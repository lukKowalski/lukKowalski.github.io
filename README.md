# lukKowalski.github.io

A Heroes of Might & Magic III-style water mill scene in Three.js — single-file `index.html`
(textures are procedural, audio is embedded). Click the wheel to spin it.

Built from `water-mill.html` with `build.py` (strips the dev button bar).
The previous Next.js site is preserved at tag `nextjs-site` and on the `gh-pages` branch.
